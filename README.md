## 🚀 Installation & Setup (VS Code)

1. Clone or download this repository.
2. Open the **entire folder** in VS Code (important: don't just open the file, open the whole folder so VS Code detects the `.vscode` configuration).
3. Open your `.algo` or `.pseudo` file.
4. Press **F5** to run. The compiler will handle everything in the background!
